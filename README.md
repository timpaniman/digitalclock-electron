# Digital Clock (Electron)

A small Windows desktop digital clock built with [Electron](https://www.electronjs.org/).

## Requirements

- [Node.js](https://nodejs.org/) 18+

## Run from source

```bash
git clone https://github.com/timpaniman/digitalclock-electron.git
cd digitalclock-electron
npm install
npm start
```

## Build an installer

```bash
npm run dist
```

The NSIS installer is written to `dist/DigitalClock-Setup-1.0.0.exe`.
